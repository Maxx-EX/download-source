# Download source

Dual-channel Android downloader powered by **Zero-core engine** (NDK/C++ segmented multi-thread download).

| Channel | Package | APK |
|---------|---------|-----|
| **Zeta** (test)   | `com.downloadsource.zeta`  | `DownloadSource-Zeta-1.0.0-debug.apk` |
| **Omega** (release) | `com.downloadsource.omega` | `DownloadSource-Omega-1.0.0-debug.apk` |

## Features
- Zero-core engine: native segmented download, multi-thread, resume
- Custom download directory (SAF `ACTION_OPEN_DOCUMENT_TREE`)
- Built-in WebView search with Baidu redirect / ad interception
- GitHub automatic acceleration + editable mirror sources
- Global crash screen
- Gradient UI, day / night themes
